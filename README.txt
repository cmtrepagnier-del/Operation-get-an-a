# Operation Get an A

First working version for iPad:
- ACCT 2302 + ECON 2301
- 60 questions for each subject
- one question at a time
- Apple Pencil scratchpad
- Check Answer
- self-grade Correct / Missed
- Missed Queue
- Reset
- progress saved locally on the device
- installable as a Home Screen web app

Upload these five files to the ROOT of the GitHub repository:
- index.html
- manifest.webmanifest
- sw.js
- icon-192.png
- icon-512.png

Then enable GitHub Pages:
Settings > Pages > Deploy from a branch > main > /(root) > Save.
